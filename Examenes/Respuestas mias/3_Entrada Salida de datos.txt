    a_  
        getchar recibe un caracter unico 
            char c = getchar();
        putchar muestra por pantalla un unico caracter 
            putchar(c);
    b_ 
        gets permite que se introduzca una linea de texto, toma hasta el primer salto de linea y si no hay hasta que acabe el archivo 
        fgets es como gets pero permite especificar el tamaño maimo que puede almacenar y el tipo de entrada como stdin 
        se recomienda fgets porque gets esta obsoleto, ademas no tiene limite, si el texto es demaciado grande lo almacena igual jugando con los limites del buffer 
    c_
        puts muetra una linea de texto por pantalla y al final introduce un salto de linea 
            puts("Este es un texto"); --> imprimira ese texto y despues un salto de linea  
        fputs no introduce el salto de linea, pero en cambio permite especificar el tipo de salida como stdin   
            puts("Este es un texto", stdin); --> imprimira el texto pero no habra salto de linea 
        ademas ninguno permite la anidacion de texto con el contenido de variables como uno

    a_ es una palabra clave o caracter clave que permite especificar que tipo de dato se pondra en ese lugar, para posteriormente ser reemplazado por una variable de tal tipo de dato 
        %i o %d --> sirve para imprimir numeros enteros junto a una cadena de texto printf("Mi edad es %d", edad);
        %c --> imprimer un caracter unico junto a la cadena printf("Mi inicial es: %c", inicial);
        %.nf --> sirve para mostrar un flotante y n cantidad de decimales printf("Te debo $%.2f", dinero);
    b_
        la presicion es con el flotante: printf("Presicion de 2 decimales: %.2f", numero);
        el ancho con un numero entre corchetes: printf("Diex espacios minimo: [%10d]", numero)
    c_
        \n realiza un salto de linea printf("Introduzca su edad: \n");
        \t realiza una tabulacion printf("Hola \t Bye"); (en realidad no sabria en que poner una tabulacion, por eos la puse ahi por poner)
