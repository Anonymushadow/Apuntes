    a) 
        malloc: se usa para asignar un bloqu de memoria dinamica, lo usaria para casos donde necesito crear un espacio no fijo 
            int *p = (int *)malloc(sizeof(int) * 1); // cree espacio para un entero 
        calloc: es como malloc pero al momento de crerse se llena con caracteres nulos, osea '\0' para char y 0 para otros lo usaria si quiero despues hacer verificaciones de completado o no pero si no no sabria bien ahora en que puedo usarlo especificamente
            char *p = (char *)calloc(10, sizeof(char)); // cree un array dinamico de 10 caracteres 
        realloc: sirve para modificar el tamaño de un dato dinamico ya creado, lo usaria en casos de requerir mas espacio o que el actual sea demaciado grande para lo necesario, como una variable para almacenar nombres que de repente se reutiliza para almacenar correos electronicos
            char *p = (char *)malloc(10, sizeof(char));
            p = (char *)realloc(p, sizeof(char) * 5); // aca redimencione el array de 10 digitos a 5 
        free: se utiliza para poder liberar memoria y evitar saturacion del sistema, lo usaria para eliminar datos que ya no necesitare pero ocuparian espacio  
            free(p);
            p = NULL;
    b) es cuando por accidente teniendo una memoria dinamica sobreescribis el puntero que tenia su direccion, esto provoca que esa memoria dinamica siga estando ocupada debido a que no se hizo un free pero no hay manera de acceder a esta debido a que no tenemos la direccion 
        para prevenirlo podriamos no ser brutos, liberar las memorias que no usamos y asignarles NULL para hacer una verificacion del contenido y de ese modo no sobreescribir algo util
