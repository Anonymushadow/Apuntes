Entorno de Desarrollo:
    Instalación de un compilador (GCC, Clang).
    Uso de un IDE o editor de texto.
    Compilación de un programa desde la linea de comandos
    Linea de comandos: es una interfaz de texto especifico para trabajar con el sistema operativo de una manera no grafica
        basicamente es manejar el sistema evitando su interfaz grafica 
    Terminal: es una aplicacion que ejecuta una ventana que utilizamos para ejecutar lineas de comandos 
    CMD: es la interfaz de linea de comandos que se utiliza en windows (entre otras se usa CMD)
    PowerShell: es una interfaz de linea de comandos mas avanzada que el CMD con comandos nuevos
    Consola: es una forma generica de llamar a una interfaz de linea de comandos como CMD, Powershell, etc
Concepto de Compilación (Introducción):
    ¿Qué es un compilador?
    Cómo se compila un programa en C.

Sintaxis Básica:
    Estructura del código.
    Importancia de la sintaxis correcta.
IDE Vs Editor de texto:
    Editor de texto: Es una herramienta para escribir y editar texto
        Ofrecen opciones basicas como cambiar el color, subrayar, etc 
        Algunos permite la administracion de archivos 
    IDE: Es un tipo de editor de texto enfocado al desarrollo de software 
        Tiene las funciones basicames de muchos editores de texto 
        Contiene compiladores incluidos para evitar compilar a "mano"
        Contiene herramientas o marcas que permiten detectar fallas en el codigo y arreglarlas
        Facilita la organizacion de proyectos y recursos 
        Suelen integrar softwares para amnejod e versiones como GIT 
        Pueden incluir interfaces graficas
